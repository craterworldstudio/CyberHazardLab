# SSH Service

SSH represents a secure remote-access service.

CHL includes SSH protocol/service components under:

- `backend/services/ssh.py`
- `backend/protocols/ssh_protocol.py`

## Educational role

The simulated SSH service can demonstrate:

- TCP service availability
- port-based service discovery
- client/server sessions
- authentication concepts

It is not intended to provide a real SSH server accessible from the host machine.
