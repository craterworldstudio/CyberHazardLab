# Hosts

Hosts are simulated end systems.

A host can have:

- one or more interfaces
- MAC addresses
- IP configuration
- services
- protocol state

Examples include a simulated PC or web server.

## Host versus device

A host is primarily an endpoint, while other device types such as switches and routers provide infrastructure behavior.

## Services

A host may run simulated services such as:

- HTTP
- SSH
- Echo
- DNS
- DHCP

The exact combination depends on the scenario.

## Management

NCM can expose host health, configuration, services, and interfaces through the management UI.
