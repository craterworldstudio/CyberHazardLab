# Development Setup

Cyber Hazard Lab is designed to run locally.

## Requirements

The project primarily requires:

- Python 3
- a modern web browser
- Git

The exact Python version should follow the version currently supported by the repository.

## Running

The application entry point is under `application/`.

The project uses Python's built-in HTTP server approach rather than Flask.

## Development workflow

1. Clone the repository.
2. Create or activate a Python environment if desired.
3. Install only dependencies actually required by the current repository.
4. Start the application.
5. Open the local web interface.
6. Test simulation behavior before modifying frontend presentation.

## Philosophy

Keep the project lightweight. Avoid introducing frameworks merely to solve problems that can be handled cleanly with the existing architecture.
