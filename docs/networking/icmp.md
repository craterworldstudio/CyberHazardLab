# ICMP

ICMP provides network-control and diagnostic messaging.

In CHL it is useful for implementing familiar operations such as simulated ping behavior.

## Conceptual flow

```text
ICMP Echo Request
        ↓
Destination
        ↓
ICMP Echo Reply
```

ICMP can also represent error conditions generated by network devices.

## Educational purpose

ICMP is useful because it gives users a simple way to observe the difference between:

- Layer 2 connectivity
- Layer 3 reachability
- transport availability
- application availability

A successful ping does not imply that an HTTP or SSH service is available.
